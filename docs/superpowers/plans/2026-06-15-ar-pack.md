# AR (Arabic) Language Pack Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a complete Arabic (العربية) language pack that exercises all remaining untested ScriptProfile flags — abjad script type, RTL direction, consonantMatra decomposability, positionalForms=true, and vowelPoints tone system.

**Architecture:** Single seed file `lib/packs/ar/ar_seed.dart` following the exact pattern of ES/KO/ZH packs. The AR profile is the first to combine positionalForms=true and hasToneSystem=true simultaneously, which triggers both `positionalForm` games (rung 3 and 4) and `toneVowelMatch` (rung 0) — 8 game specs total. Char decomposition uses consonantMatra: each Arabic letter splits into base consonant glyph + vowel diacritic mark, stored as two charComponents rows.

**Tech Stack:** Flutter/Dart, Drift/SQLite (via `LearningDb.forTesting()` / `NativeDatabase.memory()`), `flutter_test`, existing `gameAvailability()` pure function from `lib/core/games/game_availability.dart`.

## Context for implementer

The codebase already has ES (alphabet), KO (hangul/jamo), ZH (logographic/radicals) packs. The `game_availability_test.dart` already defines a `_arProfile` const and has 8 passing tests for it — but no actual AR seed or ar_seed_test.dart exists yet. The game availability logic is already correct; this task only adds data.

**Non-negotiable invariants that affect this task:**
- **I4:** Concepts are shared across packs. Use the existing `concept_dog`, `concept_cat`, `concept_water`, `concept_eat`, `concept_house` concept IDs. All inserts use `insertOnConflictUpdate` (idempotent).
- **I5:** Game availability is computed from ScriptProfile flags only — no Arabic-specific game logic. The AR pack must set the right flags so `gameAvailability()` returns all 8 expected specs.
- **I8:** No Arabic-specific code in core. Only `lib/packs/ar/` and `test/packs/ar/`.

**Key ScriptProfile values for AR** (match `_arProfile` in `test/core/games/game_availability_test.dart`):
- `scriptType: 'abjad'`
- `direction: 'rtl'`
- `decomposability: 'consonantMatra'`
- `positionalForms: true` ← positionalForm game at rung 3+4
- `toneSystem: 'vowelPoints'` ← toneVowelMatch game at rung 0
- `needsScriptTrack: true`
- `transliteration: 'romanization'` (learners need Roman transcription)
- `inputMethods: ['keyboard']`

**Expected `gameAvailability(arProfile)` output (8 specs):**
```
mnemonicMatch  rung 1  (consonantMatra ≠ atomic → isDecomposable)
readingBlitz   rung 2  (always)
componentBuild rung 3  (decomposable, non-alphabet)
positionalForm rung 3  (positionalForms=true)
positionalForm rung 4  (positionalForms=true)
writeTrace     rung 4  (always)
wordBuild      rung 5  (abjad is not logographic)
toneVowelMatch rung 0  (vowelPoints → hasToneSystem)
```

```dart
import 'dart:convert';

import 'package:drift/drift.dart';

import '../../core/db/learning_db.dart';

Future<void> seedArPack(LearningDb db) async {
  await db.transaction(() async {
    await db.into(db.scriptProfiles).insertOnConflictUpdate(
          ScriptProfilesCompanion(
            id: const Value('sp_ar'),
            scriptType: const Value('abjad'),
            direction: const Value('rtl'),
            decomposability: const Value('consonantMatra'),
            positionalForms: const Value(true),
            toneSystem: const Value('vowelPoints'),
            needsScriptTrack: const Value(true),
            transliteration: const Value('romanization'),
            inputMethodsJson: Value(jsonEncode(['keyboard'])),
          ),
        );

    await db.into(db.languages).insertOnConflictUpdate(
          const LanguagesCompanion(
            id: Value('lang_ar'),
            name: Value('العربية'),
            scriptProfileId: Value('sp_ar'),
            ttsVoice: Value('ar-SA'),
            enabled: Value(true),
          ),
        );

    // Concepts — shared pool (I4). insertOnConflictUpdate is idempotent.
    final conceptRows = <(String, String, String, String)>[
      ('concept_dog', 'dog', 'noun', 'image'),
      ('concept_cat', 'cat', 'noun', 'image'),
      ('concept_water', 'water', 'noun', 'image'),
      ('concept_eat', 'eat', 'verb', 'clip'),
      ('concept_house', 'house', 'noun', 'image'),
    ];
    for (final (id, gloss, pos, assetType) in conceptRows) {
      await db.into(db.concepts).insertOnConflictUpdate(
            ConceptsCompanion(
              id: Value(id),
              glossKey: Value(gloss),
              partOfSpeech: Value(pos),
              defaultAssetType: Value(assetType),
            ),
          );
    }

    // Lexemes — writtenForm = Arabic abjad, reading = romanized transcription
    final lexemeRows = <(String, String, String, String)>[
      ('lex_ar_dog', 'concept_dog', 'كلب', 'kalb'),
      ('lex_ar_cat', 'concept_cat', 'قطة', 'qitta'),
      ('lex_ar_water', 'concept_water', 'ماء', 'maa'),
      ('lex_ar_eat', 'concept_eat', 'أكل', 'akala'),
      ('lex_ar_house', 'concept_house', 'بيت', 'bayt'),
    ];
    for (final (id, conceptId, form, reading) in lexemeRows) {
      await db.into(db.lexemes).insertOnConflictUpdate(
            LexemesCompanion(
              id: Value(id),
              languageId: const Value('lang_ar'),
              conceptId: Value(conceptId),
              writtenForm: Value(form),
              reading: Value(reading),
              cefrBand: const Value('A1'),
            ),
          );
    }

    // Characters — 5 Arabic letters (needsScriptTrack = true)
    // consonantMatra decomposability: base consonant + vowel diacritic
    // ب (ba) + fatha (َ, above) → [ba] sound
    // ت (ta) + kasra (ِ, below) → [ti] sound
    // ن, م, ا — standalone (no components; alif is a special vowel carrier)
    final charRows =
        <(String, String, List<String>, String, List<(String, String)>)>[
      ('char_ar_ba', 'ب', ['b'], 'letter ba',
          [('ب', 'base'), ('َ', 'above')]),
      ('char_ar_ta', 'ت', ['t'], 'letter ta',
          [('ت', 'base'), ('ِ', 'below')]),
      ('char_ar_nun', 'ن', ['n'], 'letter nun', []),
      ('char_ar_mim', 'م', ['m'], 'letter mim', []),
      ('char_ar_alif', 'ا', ['a', 'aa'], 'letter alif', []),
    ];
    for (final (charId, glyph, readings, meaning, components) in charRows) {
      await db.into(db.characters).insertOnConflictUpdate(
            CharactersCompanion(
              id: Value(charId),
              languageId: const Value('lang_ar'),
              glyph: Value(glyph),
              readingsJson: Value(jsonEncode(readings)),
              meaning: Value(meaning),
            ),
          );
      for (final (compGlyph, position) in components) {
        await db.into(db.charComponents).insertOnConflictUpdate(
              CharComponentsCompanion(
                id: Value('${charId}_$position'),
                characterId: Value(charId),
                componentGlyph: Value(compGlyph),
                position: Value(position),
              ),
            );
      }
    }

    await db.into(db.canDoGoals).insertOnConflictUpdate(
          const CanDoGoalsCompanion(
            id: Value('cando_ar_a1_abjad'),
            languageId: Value('lang_ar'),
            cefrBand: Value('A1'),
            description:
                Value('I can recognize basic Arabic letters and read simple words'),
          ),
        );
  });
}
```
