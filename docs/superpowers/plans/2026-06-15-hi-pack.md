# HI (Hindi/Devanagari) Language Pack Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a Hindi (हिन्दी) language pack that exercises the last two untested ScriptProfile values — `abugida` script type and `baseDiacritics` decomposability — completing full coverage of all `ScriptType` and `Decomposability` enum variants.

**Architecture:** Single seed file `lib/packs/hi/hi_seed.dart` following the exact pattern of AR/KO/ZH packs. Devanagari is an abugida: each syllable unit is a base consonant + vowel diacritic (matra). Two characters (का, कि) are seeded with two charComponents each (base consonant glyph + matra glyph at named position) to prove baseDiacritics decomposition. Three standalone consonants (ग, म, प) with inherent 'a' carry no explicit matra and have no charComponents rows. The HI ScriptProfile has `positionalForms=false` and `toneSystem=none`, so `gameAvailability` produces 5 specs — different from AR's 8.

**Tech Stack:** Flutter/Dart, Drift/SQLite (`LearningDb.forTesting()` / `NativeDatabase.memory()`), `flutter_test`, existing `gameAvailability()` from `lib/core/games/game_availability.dart`.

## Context for implementer

The codebase has packs for: ES (alphabet/atomic), JA (syllabary/atomic), ZH (logographic/radicals), KO (hangul/jamo), AR (abjad/consonantMatra). Hindi/Devanagari adds the 6th `ScriptType` (abugida) and 5th `Decomposability` (baseDiacritics). Existing game logic already handles this — no core changes needed.

**Non-negotiable invariants:**
- **I4** — Use shared concept IDs: `concept_dog`, `concept_cat`, `concept_water`, `concept_eat`, `concept_house`. All inserts use `insertOnConflictUpdate`.
- **I5** — Game availability computed from ScriptProfile flags only. HI must produce exactly 5 game specs from `gameAvailability()`.
- **I8** — No Hindi-specific code in core. Only `lib/packs/hi/` and `test/packs/hi/`.

**Expected ScriptProfile:**
```
id:               'sp_hi'
scriptType:       'abugida'
direction:        'ltr'
decomposability:  'baseDiacritics'
positionalForms:  false
toneSystem:       'none'
needsScriptTrack: true
transliteration:  'romanization'
inputMethods:     ['keyboard']
```

**Expected `gameAvailability(hiProfile)` — 5 specs:**
```
mnemonicMatch   rung 1   (baseDiacritics ≠ atomic → isDecomposable=true)
readingBlitz    rung 2   (always)
componentBuild  rung 3   (decomposable + non-alphabet)
writeTrace      rung 4   (always)
wordBuild       rung 5   (abugida ≠ logographic)
```
No `positionalForm` (positionalForms=false), no `toneVowelMatch` (toneSystem=none).

**Devanagari baseDiacritics model:**
Each aksara (syllable) = base consonant + vowel diacritic (matra). Examples:
- का (kaa) = क (base consonant, position `'base'`) + ा (aa-matra, position `'right'`)
- कि (ki)  = क (base consonant, position `'base'`) + ि (i-matra, position `'above_left'`)

Standalone consonants ग, म, प carry an inherent 'a' vowel with no explicit matra glyph → no charComponents rows for those.

```dart
import 'dart:convert';

import 'package:drift/drift.dart';

import '../../core/db/learning_db.dart';

Future<void> seedHiPack(LearningDb db) async {
  await db.transaction(() async {
    await db.into(db.scriptProfiles).insertOnConflictUpdate(
          ScriptProfilesCompanion(
            id: const Value('sp_hi'),
            scriptType: const Value('abugida'),
            direction: const Value('ltr'),
            decomposability: const Value('baseDiacritics'),
            positionalForms: const Value(false),
            toneSystem: const Value('none'),
            needsScriptTrack: const Value(true),
            transliteration: const Value('romanization'),
            inputMethodsJson: Value(jsonEncode(['keyboard'])),
          ),
        );

    await db.into(db.languages).insertOnConflictUpdate(
          const LanguagesCompanion(
            id: Value('lang_hi'),
            name: Value('हिन्दी'),
            scriptProfileId: Value('sp_hi'),
            ttsVoice: Value('hi-IN'),
            enabled: Value(true),
          ),
        );

    // Concepts — shared pool (I4). insertOnConflictUpdate is idempotent.
    final conceptRows = <(String, String, String, String)>[
      ('concept_dog', 'dog', 'noun', 'image'),
      ('concept_cat', 'cat', 'noun', 'image'),
      ('concept_water', 'water', 'noun', 'image'),
      ('concept_eat', 'eat', 'verb', 'clip'),
      ('concept_house', 'house', 'noun', 'image'),
    ];
    for (final (id, gloss, pos, assetType) in conceptRows) {
      await db.into(db.concepts).insertOnConflictUpdate(
            ConceptsCompanion(
              id: Value(id),
              glossKey: Value(gloss),
              partOfSpeech: Value(pos),
              defaultAssetType: Value(assetType),
            ),
          );
    }

    // Lexemes — writtenForm = Devanagari, reading = romanized transcription
    final lexemeRows = <(String, String, String, String)>[
      ('lex_hi_dog', 'concept_dog', 'कुत्ता', 'kutta'),
      ('lex_hi_cat', 'concept_cat', 'बिल्ली', 'billi'),
      ('lex_hi_water', 'concept_water', 'पानी', 'paani'),
      ('lex_hi_eat', 'concept_eat', 'खाना', 'khaana'),
      ('lex_hi_house', 'concept_house', 'घर', 'ghar'),
    ];
    for (final (id, conceptId, form, reading) in lexemeRows) {
      await db.into(db.lexemes).insertOnConflictUpdate(
            LexemesCompanion(
              id: Value(id),
              languageId: const Value('lang_hi'),
              conceptId: Value(conceptId),
              writtenForm: Value(form),
              reading: Value(reading),
              cefrBand: const Value('A1'),
            ),
          );
    }

    // Characters — Devanagari aksharas (needsScriptTrack = true)
    // baseDiacritics decomposability: base consonant + vowel matra (diacritic)
    // का (kaa) = क (base) + ा (aa-matra, right of base)
    // कि (ki)  = क (base) + ि (i-matra, above-left of base)
    // ग, म, प carry inherent 'a' — no explicit matra, no charComponents
    final charRows =
        <(String, String, List<String>, String, List<(String, String)>)>[
      ('char_hi_kaa', 'का', ['kaa'], 'ka + long a vowel',
          [('क', 'base'), ('ा', 'right')]),
      ('char_hi_ki', 'कि', ['ki'], 'ka + short i vowel',
          [('क', 'base'), ('ि', 'above_left')]),
      ('char_hi_ga', 'ग', ['ga'], 'letter ga (inherent a)', []),
      ('char_hi_ma', 'म', ['ma'], 'letter ma (inherent a)', []),
      ('char_hi_pa', 'प', ['pa'], 'letter pa (inherent a)', []),
    ];
    for (final (charId, glyph, readings, meaning, components) in charRows) {
      await db.into(db.characters).insertOnConflictUpdate(
            CharactersCompanion(
              id: Value(charId),
              languageId: const Value('lang_hi'),
              glyph: Value(glyph),
              readingsJson: Value(jsonEncode(readings)),
              meaning: Value(meaning),
            ),
          );
      for (final (compGlyph, position) in components) {
        await db.into(db.charComponents).insertOnConflictUpdate(
              CharComponentsCompanion(
                id: Value('${charId}_$position'),
                characterId: Value(charId),
                componentGlyph: Value(compGlyph),
                position: Value(position),
              ),
            );
      }
    }

    await db.into(db.canDoGoals).insertOnConflictUpdate(
          const CanDoGoalsCompanion(
            id: Value('cando_hi_a1_devanagari'),
            languageId: Value('lang_hi'),
            cefrBand: Value('A1'),
            description: Value(
                'I can recognize basic Devanagari letters and read simple Hindi words'),
          ),
        );
  });
}
```
