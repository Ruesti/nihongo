# Schriften

Beide Schriften stehen unter der SIL Open Font License 1.1 (Lizenztexte daneben).

- **Klee One** (`KleeOne-Regular.ttf`) von Fontworks Inc. — Schulheft-Handschrift für
  Japanisch in der Wörterkarte und der Wortliste. Quelle:
  https://github.com/google/fonts/tree/main/ofl/kleeone
- **Caveat** (`Caveat-Variable.ttf`) von Impallari Type — Füller-Handschrift für die
  deutschen Bedeutungen. Quelle: https://github.com/google/fonts/tree/main/ofl/caveat

Bewusst nur das Regular-Gewicht von Klee One (8,7 MB); mehr Gewichte würden die
App unnötig aufblähen.
